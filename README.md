# ScioBot e-mail assets

Public images for ScioBot e-mails sent through Ecomail. Templates load them from raw.githubusercontent.com, pinned to a commit:

`https://raw.githubusercontent.com/jan-kalasnikov-scio/sciobot-email-assets/<commit>/<folder>/<file>`

Avoid jsDelivr's `@<version>` URLs: Ecomail's preview did not load images whose URL contains `@`.

- `novinky-skoly/`: news e-mail for schools (Ecomail templates 352 and 353), November 2026.

Source designs live in the private `sciocz/sciobot-next` repository (`design/email-novinky-skoly.pen`, `docs/emails/crm-skoly/`).
